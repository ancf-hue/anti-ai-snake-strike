  # 🐍💥 Anti-AI Shield: Змея и Удар

> **3D-аркада на Three.js** — управляй змеёй, заряжай удар и разбивай цели на арене силы!



---

## 🎮 О игре

**Змея и Удар** — это динамичная аркадная игра, где вы управляете могущественной змеёй на древней арене. Ваша цель — за **3 минуты** разбить **15 целей** силой удара, чтобы заслужить легендарную награду: **Красную змею** 🐍

Игра создана в рамках проекта **Anti-AI Shield** — коллекции авторских игр, разработанных человеком без использования генеративного ИИ.

---

## 🎯 Как играть

1. **Зажми кнопку удара** ⚡ для зарядки силы
2. **Отпусти** в нужный момент — змея рванёт вперёд
3. **Разбивай цели** разных типов:
   - 📦 **Ящики** (1 очко) — лёгкая добыча
   - 🪨 **Камни** (2 очка) — требуют среднего удара
   - 💎 **Кристаллы** (3 очка) — нужны мощные удары
4. Набери **15 очков** и получи награду!

⚠️ **Внимание:** Если сила удара меньше прочности цели — змея отскочит и будет оглушена!

---

## ✨ Особенности

### 🎨 Геймплей
- **Система зарядки удара** — чем дольше держишь, тем мощнее атака
- **3 типа целей** с разной прочностью и стоимостью
- **Отдача при промахе** — тактическое мышление важнее силы
- **Таймер на 3 минуты** — азарт и вызов
- **Доска почёта** — делись результатами с другими игроками
- **Мультиязычность** (RU / EN)

### 🎵 Атмосфера
- **3D-графика** на Three.js с динамическим освещением
- **Система частиц** при разрушении целей
- **Процедурные звуки** через Web Audio API
- **Голосовая озвучка** событий через Speech Synthesis
- **Конфетти при победе** 🎉

### ⚡ Производительность
- **Адаптивная оптимизация**: автоматическое определение типа устройства
- **LITE_MODE** для мобильных: меньше сегментов, частиц, FPS 45
- **Полное отключение теней** на слабых устройствах (≤2 ГБ RAM)
- **Мульти-CDN fallback** для Three.js (Cloudflare → unpkg → jsdelivr)
- **Поддержка 100dvh** для корректного отображения на iOS Safari
- **Fallback для старых браузеров** (touch + mouse события)
